### Eindimensionale Arrays 
Eine ``Variable`` ist eine *Box* für einen ``Wert`` *int groesse = 5;*. Wenn wir aber mehrere logisch *zusammenhängende Boxen* ausgeben wollen, wäre folgendes umständlich. 

```csharp
int alterAnna = 15;
int alterBen = 16;
int alterClara = 17;
int alterDavid = 15;
int alterElena = 18;
int alterFelix = 16;
int alterGreta = 17;
int alterHans = 15;
int alterIris = 16;
int alterJonas = 17;
...

Console.WriteLine(alterAnna);
Console.WriteLine(alterBen);
Console.WriteLine(alterClara);
...
```

Es wäre angenehmer alle ``Werte`` der ``Variablen`` gemeinsam in eine neue ``Variable`` zu geben, welche mit *einem Namen* angesprochen werden kann. Zwar müssen wir uns nun merken, dass *Anna* auf der ersten *Position* ist, aber das stört uns soweit nicht. Wir sprechen jedoch *Anna* in dem ``Array`` an, indem wir ihre *Position - 1* verwenden. Wir nennen diese neue Zahl den ``Index`` und dieser beginnt bei 0. 

```csharp
//       Index: 0,   1,  2,  3, .................., 9
int[] alter = { 15, 16, 17, 15, 18, 16, 17, 15, 16, 17 }; // wir wissen die Werte
// int[] alter = new int[10] // wir wissen die Werte nicht, aber wie viele es sind - hier 10

// Die Zählvariable 'i' dient direkt als Index für das Array:
for (int i = 0; i < alter.Length; i++)
{
    // i wird im ersten Durchlauf 0, dann 1, bis hin zu 9
    Console.WriteLine(alter[i]); 
}
```

>**Wir merken uns:** 
>1) Ein ``Array`` ist eine Ansammlung von ``Werten`` welche logisch zusammengehören. 
>2) Wir legen ein ``Array`` an indem wir nach dem ``Typ`` eine *eckige Klammer* schreiben.
>3) Wenn wir wissen welche ``Werte`` in ein ``Array`` kommen, schreiben wir nach dem ``Zuweisungsoperator`` *{ "Anna", "Ben" };*. 
>4) Wenn wir *nicht* wissen welche ``Werte`` in ein ``Array`` kommen, aber wie groß es sein soll, schreiben wir nach dem ``Zuweisungsoperator`` z.B. *new int[10];* wenn wir genau *10* ``Elemente`` haben wollen. 
>5) Ein einzelner ``Wert`` welcher sich in einem ``Array`` befindet, wird ``Element`` genannt. 
>6) Ein ``Array`` besitzt mehrere ``Indices``, welche uns erlauben auf eine Position zuzugreifen. 
>7) Wir greifen auf ein ``Element`` des ``Arrays`` zu indem wir eine *eckige Klammer* nach dem *Namen* der ``Variable`` schreiben.
>8) Der ``Index`` ist immer genau um *1* kleiner als die tatsächliche Position des Elements. 
>9)  Wenn ein ``Array`` mit einer ``For-Schleife`` durchlaufen wird, muss die ``Zählvariable`` bei *0* beginnen.


Wir sehen nun folgende ``Syntax`` wie wir das gemerkte umsetzen. 
| Aktion  | C# |
| :---  | :--- |
| **Anlegen (leer)** | *int[] alter = new int[5];* |
| **Anlegen (mit Werten)** | *string[] alter = { 15, 17 };* |
| **Beschreiben an einem Index** | *zahlen[0] = 42;* |
| **Auslesen** | *zahlen[0];* |

### Erstellung eines 2D-Arrays
Wenn wir nun eine weitere Daten besitzen wie z.B. die Größe einer Person können wir ein weiteres ``Array`` anlegen. Aber wenn wir nun zusätzlich das alter der gewschister und der eltern, usw. merken wollen, haben wir wieder das gleiche Problem wie vorher mit dem individuellen Alter von Anna.

```csharp
//       Index: 0,   1,  2,  3, .................., 9
int[] alter = { 15, 16, 17, 15, 18, 16, 17, 15, 16, 17 };
int[] groesse = { 150, 160, 170, 150, 180, 160, 170, 150, 160, 170 };
...

// Die Zählvariable 'i' dient direkt als Index für das Array:
for (int i = 0; i < alter.Length; i++)
{
    // i wird im ersten Durchlauf 0, dann 1, bis hin zu 9
    Console.WriteLine(alter[i]); 
    Console.WriteLine(groesse[i]); 
}
```

Wir können nun eine *zweite Dimension* hinzufügen - ein ``2D-Array`` anlegen. Wir fügen dazu ein *Komma* in den eckigen Klammern neben dem ``Typ`` hinzu *[,]*. 

```csharp
//       Index: 0,   1,  2,  3, .................., 9
int[,] personendaten = 
{ 
    { 15, 16, 17, 15, 18, 16, 17, 15, 16, 17 },
    { 150, 160, 170, 150, 180, 160, 170, 150, 160, 170 }
};
...

// Die Zählvariable 'i' dient direkt als Index für das Array:
for (int y = 0; y < personendaten.GetLenth(0); y++)
{
    for (int x = 0; x < personendaten.GetLength(1); x++)
    {
        Console.WriteLine(personendaten[y,x]);
    } 
}
```

Wenn wir nicht wissen was *konkret* ins das ``Array`` reinkommt, schreiben wir folgendes.

```csharp
int[,] personendaten = new int[10,4]
``` 

Die Bedeutung ist dass wir jeweils 10 individien wie Anna aufnehmen können und von jedem dieser nun *vier* ``Werte`` speichern können. Z.B. *Alter*, *Körpergröße*, *Schuhgröße* und *Haarlänge*.

>**Wir merken uns:**
>10) Weitere ``Dimensionen`` können dem ``Array`` hinzugefügt werden indem wir mehrere *Kommas* zwischen eckigen Klammern *int[,,] personendaten;* schreiben.


### Y- vs. X-Achse (Zeilen und Spalten)
Wenn wir nun *Schachbretter*, *Muster* oder *Hamster* in der ``Console`` darstellen wollen, bieter sich das ``Array`` als ``Datenstruktur`` durch seine *TODO* an. 

Grafisch können wir uns es folgendermaßen vorstellen. Die blauen Zahlen sind die ``Indices`` und stellen für jedes ``Element`` eine eindeutige *Kennung* dar. Wenn wir also einen *Hamster* fragen wo er sich befindet, kann dieser Mithilfe von der x- und y-Koordinate dem ``2d-Array`` *brett* mitteilen wo dieses ein 🐹-Symbol zeichnen soll. 

```
        x
 🟦0️⃣1️⃣2️⃣3️⃣4️⃣
 0️⃣🟫🟫🟫🟫🌱
 1️⃣🟫🟫🟫🌱🌱
y2️⃣🌱🌱🟫🌱🌱
 3️⃣🟫🐹🌱🌱🌱
 4️⃣🟫🟫🟫🌱🌱
 5️⃣🟫🌱🟫🌱🌱
 6️⃣🟫🟫🟫🟫🌱
```


Das obige Feld kann mithilfe von folgendem ``Array``
```csharp
string[,] brett = new string[7,5]
```
umgesetzt werden. Geschrieben wird der 🐹 an der Stelle und ebenso ausgelese.
```csharp
brett[3,1] = "🐹";
Console.PrintLine(brett[3,1]); // 🐹
```

>**Wir merken uns:** 
>11) Wir betrachten bei einem ``2d-Array`` zuerst die y-Achse, dann die x-Achse bei Erstellung, Lese- und Schreibzugriffen.
>12) Die y-Achse zählt von oben nach unten mit positiven Zahlen und die x-Achse mit positiven Zahlen von links nach rechts. 


### Ausgabe mit Zählschleifen
Um ein ``2D-Array`` zu durchlaufen und auf die ``Console`` auszugeben, nutzten wir ``verschachtelte Schleifen``. Die äußere ``Zählschleife`` (meist eine [``for-Schleife``](05_Glossar.md#for-schleife)) iteriert über die Zeilen (y), die innere über die Spalten (x). 

```csharp
// Zuständigkeit: Iteriert über die Y-Achse (Zeilen)
for (int y = 0; y < brett.GetLength(0); y++) 
{
    // Zuständigkeit: Iteriert über die X-Achse (Spalten)
    for (int x = 0; x < brett.GetLength(1); x++)
    {
        Console.Write(_plane[i, j]); // Ausgabe des Symbols ohne Umbruch
    }
    Console.WriteLine(); // Neue Zeile für die nächste Y-Position
}
```

Der Grund für die ``Verschachtelung`` ist, dass für jedes ``Element`` in der x-Dimension genau ein ``Index`` für die y-Achse notwenidg ist.


>**Wir merken uns:** 
>13) Um ein ``2d-Array`` abzuarbeiten, benötigen wir für jede ``Dimension`` eine eigene Schleife. Zusammen sind diese ``verschachtelte Schleifen``.
>14) Wir können das ``Array`` mit der ``Methode`` *brett.GetLength(0)* fragen wie viele ``Elemente`` dieses in der ``DImension`` *0* hat. Gleiches gilt für ``Dimension`` *1* und *brett.GetLength(1)*.

### Übergabe an Methoden 
``Arrays`` sind sogenannte ``Verweistypen`` (``Reference Types``). 
Wenn ein ``2D-Array`` als ``Parameter`` an eine ``Methode`` übergeben wird, wird **nicht** das gesamte ``Array`` in die ``Methode`` kopiert. Es wird eine ``Referenz``, die Speicheradresse für den ``Heap`` welche im ``Stack`` steht, auf das Array übergeben (``Reference Type Semantik``). Wenn ìnnerhalb der ``Methode`` Daten durch eine ``Zuweisung`` überschrieben wird, wird dieses Symbol direkt im originalen ``Array`` außerhalb der ``Methode`` geändert unabhängig wie die ``Variablen`` heißen. Das wird ein ``Seiteneffekt`` genannt.

>**Wir merken uns:** 
>15) ``Arrays`` sind ``Verweistypen``. Reichen wir sie an eine ``Methode`` weiter, arbeitet diese stets auf den **originalen Daten**. Änderungen innerhalb der Methode sind sofort überall im Programm darüber wirksam.
>16) Ein ``Seiteneffekt`` beschreibt eine nicht direkt Sichtbare Änderung von ``Variablen``.
