Installation von Microsoft Visual Studio Enterprise 2022 bzw 2026

1. Download
    * https://azureforeducation.microsoft.com/devtools

    * Klicke im Bereich „Free Software“ auf den Link „Visual Studio Enterprise Edition 2022“.

    * Lade die Software herunter.

2. Installation

    * Führe die heruntergeladene Datei aus und starte die Installation.

    * Verwende deine Schuldaten für die Identifikation (Adresse, Schul-E-Mail usw.).

    * Für die Anmeldung wird ein zweiter Faktor benötigt. Installiere dazu am besten die Microsoft Authenticator App auf deinem Smartphone und verknüpfe sie mit deiner Schul-E-Mail-Adresse.

    * Wähle bei der Installation nur die .NET-Desktopentwicklung (C#) aus.

        >Keine weiteren Pakete installieren – das macht spätere Updates unnötig groß und langsam.
