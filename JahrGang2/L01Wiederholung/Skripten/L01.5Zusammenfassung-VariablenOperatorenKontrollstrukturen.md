# C#: Grundlegende Syntax und Konzepte der Kontrollstrukturen

## Konventionen
* Alles (Klassen, Methoden, Properties) wird in `PascalCase` statt `camelCase` geschrieben, jedoch werden ``Variablen`` in `camelCase` geschrieben.

## Einfache Typen (Primitive)
In C# nutzen wir für die Deklaration meist unser bekanntes 4er-Konstrukt: 

`<Typ>` `<Name>` `<Zuweisungsoperator>` `<Wert, Methoden/Operatoren Rückgabe Variable, von>`

```csharp
int number = 10;
int anotherNumber = 10 + 20;
int anothererNumber = number * anotherNumber; 

double floatingPoint = 20.5;
double roundedNumber = Math.Round(floatingPoint);

int convertedNumber = (int) floatingPoint;

char zeichen = 'A';
string text = "Hallo";
bool wahr = true;
```

## Einfache Operatoren
Die grundlegenden ``Operatoren`` in C#:

- ``Arithmetische Operatoren``: `+`, `-`, `*`, `/`, `%`
- ``Logische Operatoren``: `&&`, `||`, `!`
- ``Vergleichsoperatoren``: `==`, `!=`, `>`, `<`, `>=`, `<=`

## Einfache I/O-Befehle
So kommuniziert man mit der ``Console``:

```csharp
Console.WriteLine("Hallo Welt");
string eingabe = Console.ReadLine();
```

## Einfache Typumwandlungen (Typecasting)
Das explizite Umwandeln eines ``Typs`` in einen anderen:

```csharp
int number = 10;
double gleitkomma = (double) number;  // explizites Typecasting
```

## Codeblöcke und Scope
In C# werden Codeblöcke durch geschweifte Klammern `{}` definiert. ``Variablen``, die innerhalb eines Blocks deklariert sind, sind nur innerhalb dieses Blocks (dem sogenannten *Scope*) sichtbar.

## Bedingte Anweisungen und Verzweigungen
In der Programmierung unterscheiden wir logisch zwischen einer einfachen bedingten Anweisung, einer zweiseitigen Verzweigung und einer Mehrfachverzweigung. 

### 1. Bedingte Anweisung (**`if`** ohne **`else`**)
Der Code wird *nur dann* ausgeführt, wenn die Bedingung wahr (`true`) ist. Ist sie falsch, passiert schlichtweg nichts und das Programm läuft weiter.

```csharp
if (bedingung)
{
    // Code wird nur ausgeführt, wenn die Bedingung zutrifft
}
```

### 2. Verzweigung (**`if`** mit **`else`**)
Eine klassische ``Verzweigung`` bietet genau zwei Wege: Einen für `true` und einen alternativen für `false`. Es wird garantiert einer der beiden Blöcke ausgeführt.

```csharp
if (bedingung)
{
    // Code für den Fall, dass die Bedingung wahr ist
}
else
{
    // Alternativer Code für alle anderen Fälle
}
```

### 3. Mehrfachverzweigung
Gibt es mehr als zwei mögliche Pfade, sprechen wir von einer Mehrfachverzweigung. In C# setzen wir diese auf zwei verschiedene Arten um:

#### Variante A: **`if`** mit **`else if`** und **`else`**
Ideal für komplexe Bedingungen, logische Verknüpfungen oder Wertebereiche (z. B. "größer als 10 und kleiner als 20").

```csharp
if (bedingung1)
{
    // Code für Bedingung 1
}
else if (bedingung2)
{
    // Code für Bedingung 2
}
else
{
    // Code, wenn keine der vorherigen Bedingungen zutrifft
}
```

#### Variante B: **`switch`**-Anweisung
Eine übersichtlichere Alternative zur Mehrfachverzweigung, wenn eine einzige ``Variable`` auf konkrete, feste Werte geprüft werden soll. Verwendet die **Schlüsselwörter** **`switch`**, **`case`**, **`break`** und **`default`**:

```csharp
switch (wert)
{
    case 1:
        // Code für den Fall, dass wert == 1 ist
        break;
    case 2:
        // Code für den Fall, dass wert == 2 ist
        break;
    default:
        // Fallback-Code (wie das else bei der if-Anweisung)
        break;
}
```

#### Variante C: Einfache Musterabgleichsausdrücke (Switch Expression)
In neueren C#-Versionen gibt es die *Switch Expression*, die primär dafür gedacht ist, einen ``Wert`` kompakt und einzeilig direkt zuzuweisen.

Für kompakten, einzeiligen Code:
```csharp
int day = 3;

string dayName = day switch
{
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    4 => "Thursday",
    5 => "Friday",
    6 => "Saturday",
    7 => "Sunday",
    _ => "Invalid day" // Der Unterstrich _ entspricht dem 'default'
};

Console.WriteLine(dayName);
```

Für mehrzeiligen Code **gibt es dieses Konstrukt in C# nicht**. Wenn komplexe Logik oder mehrere Zeilen pro Fall benötigt werden, muss zwingend das klassische **`switch`**-Statement (Variante B) verwendet werden.

## Schleifen
Die klassische ``Zählschleife`` (**`for`**) und die While-Schleife (**`while`**):

```csharp
// Wir wissen wie oft wir wiederholen.
for (int i = 0; i < 10; i++)
{
    // Code
}


// Wir wissen nicht wie oft wir wiederholen.
bool userIstFertigMitDerEingabe = ...;

while (!userIstFertigMitDerEingabe)
{
    Console.WriteLine("Bitte Eingabe erneut eingeben");
    userIstFertigMitDerEingabe = ...;
}
```

## Arrays (1D und 2D)
C# unterscheidet bei mehrdimensionalen Datenstrukturen zwischen echten, gitterförmigen ``2D-Arrays`` (Multidimensional) und ineinander verschachtelten ``Arrays`` (Jagged Arrays).

**Multidimensional Array (Echtes 2D-Array):**
```csharp
int[] array = new int[5];  // eindimensional
int[,] matrix = new int[5, 10];  // zweidimensional (perfektes Gitter)

int laenge = array.Length;  // Länge des 1D-Arrays
int zeilen = matrix.GetLength(0);  // Anzahl der Zeilen = 5
int spalten = matrix.GetLength(1);  // Anzahl der Spalten = 10
```

**Jagged Array (Array von Arrays):**
Erlaubt uns, Zeilen mit unterschiedlichen Längen zu erstellen.
```csharp
int[] array = new int[5];  // eindimensional
var jagged = new int[5][]; // 2. Klammer muss leer bleiben!

for (var i = 0; i < jagged.Length; i++) 
{
    // Lege an jeder Stelle i ein neues Array an (hier alle mit Länge 5)
    jagged[i] = new int[5];
    for (var j = 0; j < jagged[i].Length; j++)
    {
        jagged[i][j] = 0;
    }
} 

int zeilen = jagged.Length;  // Anzahl der "Zeilen" = 5 (Länge des 1. Arrays)
int spalten = jagged[0].Length;  // Anzahl der Spalten der ersten Zeile
```

## Methoden
``Methoden`` bündeln Codeblöcke. Sie können Werte zurückgeben und ``Parameter`` entgegennehmen:

```csharp
public int Addiere(int a, int b)
{
    return a + b;
}
```
