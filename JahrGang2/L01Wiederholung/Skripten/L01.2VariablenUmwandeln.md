# C#: Zusammenfassung zur Variablenumwandlung (Typecasting)

In C# können ``Variablen`` zwischen verschiedenen ``Typen`` umgewandelt werden. Hier sind die häufigsten Fälle der Umwandlung:

## 1. Zahl zu Zahl (Typecasting)

Bei der Umwandlung von Zahlen gibt es zwei primäre Szenarien: das **implizite** (automatische) und das **explizite** (erzwungene) ``Typecasting``.

- **Implizites Typecasting (z. B. `int` zu `double`):** 
  Ein kleinerer oder ungenauerer ``Typ`` kann automatisch in einen größeren oder genaueren umgewandelt werden, da bei diesem Vorgang keine Daten verloren gehen können. Der ``Compiler`` erledigt dies von selbst.
  
```csharp
int intValue = 10;
double doubleValue = intValue; // Implizite Umwandlung funktioniert automatisch
```

- **Explizites Typecasting (z. B. `double` zu `int`):** 
  Wenn wir einen größeren/genaueren ``Typ`` in einen kleineren umwandeln wollen, könnten Daten verloren gehen (z. B. die Kommastellen). Um Klarheit zu schaffen und Fehler zu vermeiden, verlangt C#, dass wir dies **explizit** erzwingen. Wir schreiben den Ziel-``Typ`` dafür in runden Klammern vor den ``Wert``.
  
```csharp
double doubleValue = 10.5;
int intValue = (int)doubleValue; // Explizite Umwandlung (Die 0.5 geht dabei verloren, intValue ist 10)
```

## 2. String zu Zahl (Parsen)

Um einen ``String`` in eine Zahl umzuwandeln, können die **`Parse`**-``Methoden`` der jeweiligen ``Typen`` verwendet werden:

- **`int.Parse`:** Wandelt einen ``String`` in eine Ganzzahl um.
  
```csharp
string intString = "123";
int intValue = int.Parse(intString);
```

- **`double.Parse`:** Wandelt einen ``String`` in einen Gleitkommawert um.
  
```csharp
string doubleString = "123.45";
double doubleValue = double.Parse(doubleString);
```

- **`TryParse`:** Eine sicherere ``Methode``, die einen Wahrheitswert (`bool`) zurückgibt, um anzuzeigen, ob die Umwandlung erfolgreich war. Das verhindert, dass das Programm bei ungültigen Eingaben (z.B. Buchstaben statt Zahlen) abstürzt.
  
```csharp
string intString = "123";

// Das Schlüsselwort 'out' deklariert die Variable direkt im Methodenaufruf
if (int.TryParse(intString, out int intValue))
{
    // Wird nur ausgeführt, wenn die Umwandlung erfolgreich war.
    // intValue enthält jetzt die Zahl 123.
}
```

## 3. Zahl zu String

Ein numerischer ``Wert`` (oder auch fast jeder andere ``Typ``) kann in einen ``String`` umgewandelt werden, indem die **`ToString()`**-``Methode`` angehängt wird:

```csharp
int intValue = 123;
string intString = intValue.ToString();
```

## 4. Verwendung der Convert-Klasse

Die ``Klasse`` **`Convert`** bietet eine einfache, einheitliche Möglichkeit, verschiedenste ``Typen`` zu konvertieren:

- **`Convert.ToInt32`:** Wandelt einen ``Wert`` in eine Ganzzahl (`int`) um.
  
```csharp
string strValue = "123";
int intValue = Convert.ToInt32(strValue);
```

- **`Convert.ToDouble`:** Wandelt einen ``Wert`` in einen Gleitkommawert (`double`) um.
  
```csharp
string strValue = "123.45";
int myIntValue = 123;

double doubleValue = Convert.ToDouble(strValue);
double anotherDoubleValue = Convert.ToDouble(myIntValue); // Beides funktioniert mit der gleichen Methode!
```

- **`Convert.ToString`:** Wandelt einen ``Wert`` in einen ``String`` um (Alternative zu `.ToString()`).
  
```csharp
int intValue = 123;
string intString = Convert.ToString(intValue);
```

Diese ``Methoden`` ermöglichen eine flexible und sichere Handhabung von ``Typen`` in C#.
