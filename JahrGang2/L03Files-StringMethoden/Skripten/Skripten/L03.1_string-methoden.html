1Zugriff auf ein einzelnes Zeichen mit [ ]

Wie kann ich mit [] auf ein einzelnes Zeichen zugreifen?


    

    

      Merke: Der erste Index ist 0, der letzte ist s.Length - 1.
      Ein Index außerhalb löst eine IndexOutOfRangeException aus.
      Zeichen lassen sich nur lesen: s[0] = 'X'; ergibt einen Compilerfehler, weil Strings unveränderlich sind.
      Probiere es aus: Klicke auf ein Zeichen oder gib einen zu großen Index ein.
    

  


  
  

    
2Teilstrings mit Substring

    
Wie kann ich mit Substring auf einen Teilstring zugreifen?

    

      
      
      
    

    

    

    

    

      Merke: Substring(start, länge) – der zweite Parameter ist die Länge, nicht der Endindex!
      Substring(start) liefert alles ab start bis zum Ende.
      Alternativ gibt es seit C# 8 den Bereichsoperator s[start..ende] (Ende exklusiv).
    

  


  
  

    
3Einen String durchlaufen

    
Wie kann man einen String von vorne nach hinten durchlaufen?

    

      
      
      
      
    

    

    

    

    
Variante mit foreach (wenn man den Index nicht braucht):

    
foreach (char c in s)
{
    Console.WriteLine(c);
}

    
Rückwärts durchlaufen:

    
for (int i = s.Length - 1; i >= 0; i--)
{
    Console.Write(s[i]);   // "ollaH"
}

    
Merke: for braucht man, wenn der Index wichtig ist (z. B. Position merken, jedes 2. Zeichen). foreach ist kürzer, wenn nur jedes Zeichen der Reihe nach interessiert.

5Ein char mit ToString() in einen String umwandeln

    
Wie kann ich ein einzelnes Zeichen mit ToString() in einen String umwandeln?

    

      
      
    

    

      
CodeTypErgebnis

      
    

    
char c = 'a';
string t = c.ToString();     // "a"
string u = s[0].ToString();  // erstes Zeichen von s als String

    

      Stolperfalle: char + char rechnet mit den Zeichencodes und ergibt eine Zahl.
      Erst mit ToString() (oder einem String auf einer Seite) entsteht Text.
