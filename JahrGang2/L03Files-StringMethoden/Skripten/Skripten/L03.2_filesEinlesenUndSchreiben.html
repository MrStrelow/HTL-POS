Übersicht: Alle verwendeten C#-Befehle für File I/O & Validierung

Wann verwendet man File.ReadAllLines und wann StreamReader?

1. File-Klasse (Komplett-I/O im RAM)

File.WriteAllLines("datei.txt", array); Schreibt ein komplettes string[] in einem Schritt auf die Festplatte.
string[] lines = File.ReadAllLines("datei.txt"); Lädt alle Zeilen auf einmal als string[] in den Managed Heap. Perfekt für kleine Configs mit foreach.
if (!File.Exists("datei.txt")) { return; } Prüft vor dem Lesen, ob die Datei auf der Festplatte vorhanden ist.

2. StreamReader / Writer & Port-Check

using (StreamReader sr = new StreamReader(pfad)) Liest mit while ((line = sr.ReadLine()) != null) Zeile für Zeile. Braucht fast keinen Heap-Speicher!
int.TryParse(val, out int port) && port >= 1 && port <= 65535 Prüft sicher, ob val eine ganze Zahl ist UND im gültigen TCP/UDP-Portbereich liegt.
!string.IsNullOrWhiteSpace(val) Prüft beim Server-Namen, ob tatsächlich ein gültiger Text hinter dem = steht.
