# 2D-Arrays 🗺️
Animierte Folien dazu: [L04.1_2DArrays.html](L04.1_2DArrays.html)

## 1. Vom 1D-Array zum 2D-Array
Ein **1D-Array** ist eine Reihe von Kästchen. Jedes Kästchen hat **einen** Index.
```csharp
string[] zeile = new string[4];   // [0] [1] [2] [3], am Anfang alle null
zeile[2] = "🌳";

// Werte direkt angeben - die Laenge (4) zaehlt C# selbst
string[] zeile = new string[] { "🟦", "🟦", "🌳", "🗻" };
string[] zeile = { "🟦", "🟦", "🌳", "🗻" };   // Kurzform, nur bei der Deklaration
int anzahl = zeile.Length;                     // 4
```
Für eine Karte mit vielen Zeilen bräuchten wir viele Variablen (``zeile0``, ``zeile1``, …) – unpraktisch, und mit einer Schleife kommen wir nicht an „die nächste Variable“.
Deshalb schieben wir die Reihen zu **einem rechteckigen Block** zusammen: dem **2D-Array**.
```csharp
string[,] karte = new string[3, 4];   // 3 Zeilen, 4 Spalten
```
Der **Beistrich** in ``[,]`` bedeutet: 2 Dimensionen. Wir verwenden **mehrdimensionale** Arrays (ein Rechteck), keine *jagged* Arrays (``string[][]``, Array von Arrays).

## 2. x- und y-Achse
```
          x →  0    1    2    3        (Spalten, GetLength(1))
     y  0    🟦   🟦   🌳   🗻
     ↓  1    🟦   🌳   🌳   🗻
        2    🟦   🟦   🌳   🌳
   (Zeilen, GetLength(0))
```
* **x** = Spalte = wie weit nach **rechts**
* **y** = Zeile = wie weit nach **unten** (anders als in Mathe – wie Zeilen in einem Text)
* Zugriff: **``karte[y, x]``** – *erst runter, dann rüber*. Gleiche Reihenfolge wie bei ``new string[Zeilen, Spalten]``.

| Ausdruck | Bedeutung | im Beispiel |
|---|---|---|
| ``karte.GetLength(0)`` | Anzahl Zeilen (Höhe) | 3 |
| ``karte.GetLength(1)`` | Anzahl Spalten (Breite) | 4 |
| ``karte.Length`` | Anzahl **aller** Felder | 12 |

## 3. Alle Felder durchlaufen
```csharp
for (int y = 0; y < karte.GetLength(0); y++)        // aeussere Schleife: Zeilen
{
    for (int x = 0; x < karte.GetLength(1); x++)    // innere Schleife: Spalten
    {
        Console.Write(karte[y, x]);
    }
    Console.WriteLine();                             // nach jeder Zeile umbrechen
}
```
Die innere Schleife läuft **komplett** durch, bevor ``y`` um 1 größer wird.
Nur eine Zeile oder Spalte? Dann reicht **eine** Schleife: ``karte[2, x]`` (Zeile 2) oder ``karte[y, 3]`` (Spalte 3).

## 4. 2D-Arrays ohne Bild: Tabellen
Auch Daten ohne grafischen Bezug passen in ein 2D-Array. Jede **Zeile** ist ein Datensatz (eine Person), jede **Spalte** ein Merkmal:

| y \ x | 0 Vorname | 1 Nachname | 2 Straße | 3 PLZ | 4 Ort | 5 Telefon |
|---|---|---|---|---|---|---|
| 0 | Anna | Huber | Hauptplatz 1 | 6020 | Innsbruck | 0660 111 |
| 1 | Max | Gruber | Bahnweg 7 | 6060 | Hall | 0664 222 |
| 2 | Lisa | Kaya | Seeufer 3 | 6200 | Jenbach | 0676 333 |

>6 Merkmale heißt **6 Spalten**, nicht 6 Dimensionen! Das Array bleibt 2-dimensional: *welche Person* und *welches Merkmal*.

## 5. Schreibweisen
```csharp
// 1) Groesse angeben, spaeter befuellen (alle Felder sind am Anfang null)
string[,] personen = new string[3, 6];
personen[0, 0] = "Anna";
personen[0, 4] = "Innsbruck";

// 2) Werte direkt angeben - jede innere { } ist EINE Zeile, die Groesse zaehlt C#
string[,] personen = new string[,]
{
    { "Anna", "Huber",  "Hauptplatz 1", "6020", "Innsbruck", "0660 111" },
    { "Max",  "Gruber", "Bahnweg 7",    "6060", "Hall",      "0664 222" },
    { "Lisa", "Kaya",   "Seeufer 3",    "6200", "Jenbach",   "0676 333" }
};

// 3) Kurzform - nur direkt bei der Deklaration erlaubt
int[,] spielfeld = { { 10, 20, 30 }, { 40, 50, 60 } };
```
⚠️ Alle Zeilen müssen **gleich lang** sein (Rechteck), sonst gibt es einen Compilerfehler.

## 6. Eine Zeile oder Spalte als 1D-Array herauslesen
Für **eine** Zeile oder Spalte reicht **eine** Schleife – ein Index bleibt fix, der andere läuft.
```csharp
// Spalte 4 (alle Orte): x = 4 bleibt fix, y laeuft
string[] orte = new string[personen.GetLength(0)];   // so viele Felder wie ZEILEN
for (int y = 0; y < personen.GetLength(0); y++)
{
    orte[y] = personen[y, 4];
}

// Zeile 0 (alles ueber Anna): y = 0 bleibt fix, x laeuft
string[] anna = new string[personen.GetLength(1)];   // so viele Felder wie SPALTEN
for (int x = 0; x < personen.GetLength(1); x++)
{
    anna[x] = personen[0, x];
}
```
⚠️ Häufiger Fehler: Eine **Spalte** ist so lang, wie es **Zeilen** gibt (``GetLength(0)``) – und umgekehrt.

## 7. Ein 2D-Muster aus einem Textfile einlesen
``weltkarte.txt``:
```
🟦🟦🟦🌳🌳🗻🗻🗻
🟦🟦🌳🌳🌳🌳🗻🗻
🟦🟦🟦🌳🌳🌳🌳🗻
```
1. ``File.ReadAllLines`` liefert ein **1D**-Array: ein ``string`` pro Zeile.
2. ⚠️ Ein Emoji besteht aus **zwei** ``char``: ``"🟦".Length == 2``. Die Breite ist also ``zeilen[0].Length / 2`` und das x-te Emoji beginnt bei Index ``x * 2``.
3. In einer verschachtelten Schleife schneiden wir jedes Emoji mit ``Substring`` heraus.
```csharp
string[] zeilen = File.ReadAllLines("../../../weltkarte.txt");

int hoehe  = zeilen.Length;
int breite = zeilen[0].Length / 2;

string[,] karte = new string[hoehe, breite];

for (int y = 0; y < hoehe; y++)
{
    for (int x = 0; x < breite; x++)
    {
        karte[y, x] = zeilen[y].Substring(x * 2, 2);
    }
}
```
Speichern geht genau umgekehrt: jede Zeile des 2D-Arrays mit ``+=`` zu einem ``string`` zusammenbauen, in ein ``string[]`` legen und mit ``File.WriteAllLines`` schreiben.

## 8. Exkurs: Warum ist ein Emoji zwei char lang? (UTF-16, UTF-8, Surrogate Pairs)
Jedes Zeichen hat in **Unicode** eine Nummer, den **Code Point** (geschrieben ``U+…`` in Hex). Unicode kennt über 1,1 Millionen Code Points (``U+0000`` bis ``U+10FFFF``, also bis zu **21 Bit**).

Ein C#-``char`` hat aber nur **16 Bit** → höchstens ``U+FFFF`` (65 536 Werte). C# speichert Texte in **UTF-16**:
* Zeichen bis ``U+FFFF`` → **ein** ``char`` (16 Bit)
* Zeichen darüber (die meisten Emojis) → **zwei** ``char`` (32 Bit), ein **Surrogate Pair**

| Zeichen | Code Point | Bit nötig | ``char`` in C# (UTF-16) | ``Length`` | Bytes im File (UTF-8) |
|---|---|---|---|---|---|
| A | U+0041 | 7 | ``0041`` | 1 | ``41`` (1 Byte) |
| ü | U+00FC | 8 | ``00FC`` | 1 | ``C3 BC`` (2 Byte) |
| ⬜ | U+2B1C | 14 | ``2B1C`` | **1** | ``E2 AC 9C`` (3 Byte) |
| 🟦 | U+1F7E6 | 17 | ``D83D DFE6`` | **2** | ``F0 9F 9F A6`` (4 Byte) |
| 🌳 | U+1F333 | 17 | ``D83C DF33`` | **2** | ``F0 9F 8C B3`` (4 Byte) |

**So entsteht ein Surrogate Pair** (Beispiel 🟦 = ``U+1F7E6``) – Schritt für Schritt in Bit.
Der wichtigste Trick: **1 Hex-Ziffer = genau 4 Bit** (``0`` = ``0000`` … ``9`` = ``1001``, ``A`` = ``1010``, ``B`` = ``1011``, ``C`` = ``1100``, ``D`` = ``1101``, ``E`` = ``1110``, ``F`` = ``1111``). Man kann Hex also ziffernweise in Bit umschreiben und zurück.

| Schritt | Bit | Hex |
|---|---|---|
| Code Point | ``0001 1111 0111 1110 0110`` | ``1F7E6`` |
| ``− 0x10000`` (löscht die führende 1) | ``0000 1111 0111 1110 0110`` | ``0F7E6`` (20 Bit) |
| in 2 × 10 Bit teilen | ``0000111101`` \| ``1111100110`` | |
| obere 10 Bit, von rechts in 4er-Gruppen | ``00 0011 1101`` | ``03D`` |
| untere 10 Bit, von rechts in 4er-Gruppen | ``11 1110 0110`` | ``3E6`` |
| **High** = ``110110`` + obere 10 Bit | ``1101 1000 0011 1101`` | ``D83D`` = ``0xD800 + 0x03D`` |
| **Low** = ``110111`` + untere 10 Bit | ``1101 1111 1110 0110`` | ``DFE6`` = ``0xDC00 + 0x3E6`` |

Die festen Bits vorne (``110110`` bzw. ``110111``) markieren „erste Hälfte“ bzw. „zweite Hälfte“. Darum sind die Werte ``D800``–``DFFF`` dafür reserviert; ein einzelner Surrogate ist kein gültiges Zeichen.

```csharp
string s = "🟦";
Console.WriteLine(s.Length);                    // 2
Console.WriteLine((int)s[0]);                   // 55357 = 0xD83D
Console.WriteLine((int)s[1]);                   // 57318 = 0xDFE6
Console.WriteLine(char.IsHighSurrogate(s[0]));  // True
Console.WriteLine(char.ConvertToUtf32(s, 0));   // 128998 = 0x1F7E6
```

**Im File** steht der Text meist als **UTF-8**: 1 bis 4 Byte (8/16/24/32 Bit) pro Zeichen – ASCII 1 Byte, Umlaute 2, ⬜ 3, 🟦 4 Byte. ``File.ReadAllLines`` übersetzt UTF-8 automatisch in UTF-16-``string``s.

Auch UTF-8 lässt sich in Bit nachrechnen: Die 21 Bit von ``U+1F7E6`` (``000 011111 011111 100110``) werden auf 4 Byte verteilt. Das erste Byte beginnt mit ``11110`` („4 Byte lang“), die anderen mit ``10`` („Fortsetzung“):

| Byte | Bit | Hex |
|---|---|---|
| 1 | ``11110`` ``000`` | ``F0`` |
| 2 | ``10`` ``011111`` | ``9F`` |
| 3 | ``10`` ``011111`` | ``9F`` |
| 4 | ``10`` ``100110`` | ``A6`` |

**Und das weiße Quadrat ⬜?** Richtig – ``U+2B1C`` passt in 16 Bit, also ist ``"⬜".Length == 1``. Mischt man es in die Karte, geht unser Trick kaputt:
```csharp
string zeile = "🟦⬜🌳";
Console.WriteLine(zeile.Length);          // 5 (nicht 6!) -> Length / 2 = 2 Spalten statt 3
Console.WriteLine(zeile.Substring(2, 2)); // "⬜" + halber Baum -> kaputtes Zeichen
```
Deshalb: In der Karte nur Emojis verwenden, die genau 2 ``char`` lang sind (🟦🟫🗻🌳🌲🌴🟨) – oder ein Trennzeichen ins File schreiben (``"🟦;⬜;🌳"``) und mit ``Split(';')`` zerlegen. Ein Guard ``if (zeile.Length % 2 != 0)`` findet ungerade Zeilen.

**Lösung 3: das Surrogate Pair abfragen.** ``char.IsHighSurrogate(zeichen)`` sagt, ob ein ``char`` die **erste Hälfte** eines Emojis ist. Dann ist das Symbol 2 ``char`` lang, sonst 1:
```csharp
int ZaehleSymbole(string zeile)
{
    int anzahl = 0;
    int i = 0;
    while (i < zeile.Length)
    {
        if (char.IsHighSurrogate(zeile[i]))
        {
            i = i + 2;     // Emoji: High + Low Surrogate
        }
        else
        {
            i = i + 1;     // z.B. ⬜: nur ein char
        }
        anzahl++;
    }
    return anzahl;
}
// ZaehleSymbole("🟦⬜🌳⬜🟦") -> 5, obwohl Length = 8
```
Zum Herausschneiden verwendet man denselben Gedanken: ``Substring(i, 2)`` oder ``Substring(i, 1)``. Achtung: Der Index ``i`` im ``string`` (``char``) und die Spalte ``x`` in der Karte (Symbol) laufen dann **nicht** mehr im Gleichschritt. → Aufgabe 5 (Winterkarte mit ⬜).
>Manche Emojis sind noch länger: ⛰️ besteht aus ``U+26F0`` + Variation Selector ``U+FE0F`` (2 ``char``, aber kein Surrogate Pair), Familien-Emojis wie 👨‍👩‍👧 aus mehreren Emojis mit Verbindern (8 ``char``).

## 9. 2D-Arrays sind Referenztypen
Wie 1D-Arrays (siehe L02): Übergeben wir eine Karte an eine Funktion und ändern sie dort, ist die **Originalkarte** verändert. Brauchen wir das Original noch, legen wir eine Kopie an:
```csharp
string[,] KopiereKarte(string[,] original)
{
    string[,] kopie = new string[original.GetLength(0), original.GetLength(1)];
    for (int y = 0; y < original.GetLength(0); y++)
    {
        for (int x = 0; x < original.GetLength(1); x++)
        {
            kopie[y, x] = original[y, x];
        }
    }
    return kopie;
}
```

## Wir merken uns
1. ``string[,] karte = new string[Zeilen, Spalten];`` – ein Rechteck mit zwei Indices.
2. Zugriff immer ``karte[y, x]``: **y = Zeile (runter)**, **x = Spalte (rüber)**.
3. ``GetLength(0)`` = Zeilen, ``GetLength(1)`` = Spalten, ``Length`` = alle Felder.
4. Alle Felder: äußere Schleife ``y``, innere Schleife ``x``.
5. Index außerhalb von ``0 … GetLength(n) - 1`` → ``IndexOutOfRangeException``.
6. Zeile/Spalte als 1D-Array: eine Schleife, ein Index fix. Spalte → Länge ``GetLength(0)``, Zeile → Länge ``GetLength(1)``.
7. Textfile → ``ReadAllLines`` (1D) → verschachtelte Schleife → 2D.
8. ``char`` = 16 Bit (UTF-16). Emojis über ``U+FFFF`` brauchen 2 ``char`` (Surrogate Pair), ⬜ nur 1. Im File: UTF-8 mit 1–4 Byte. Gemischte Zeilen zerlegt man mit ``char.IsHighSurrogate``.
